# Roadmap

## 0.2 — Trustworthy rooms

- Stable Firebase UID identity and session reconnection
- Firestore rules, emulator coverage, and atomic multiplayer writes
- Automated lint, tests, build, and dependency scanning
- Room expiration and cleanup

## 0.3 — Know the room

- Preference and relationship questionnaires
- Aggregate group profile
- Question metadata for depth, energy, style, relationship compatibility, and sensitive topics
- Deterministic question ranking with hard exclusion checks

## 0.4 — Interface overhaul

- Unified onboarding, lobby, prompt, and results layouts
- Accessible dialogs, toasts, focus states, and live announcements
- Responsive host controls and session-length pacing
- Browser-based host-and-guest tests

## 0.5 — AI-assisted beta

- Server-only generation endpoint
- Abstract group profiles with no raw names or personal answers
- Structured output, moderation, validation, caching, and rate limits
- Curated-library fallback and quality evaluation
- Host opt-in, clear AI labeling, and feedback controls

## Later

- Resume abandoned rooms
- Curated packs for dates, teams, families, reunions, and new friends
- Opt-in saved preference profiles
- Privacy-preserving session recaps
